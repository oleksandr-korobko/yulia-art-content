# Yulia Art - Content Repository

This repository contains content (markdown files and images) for the Yulia Art portfolio website.

## Structure

- `works/` - Markdown files for artworks
- `images/works/` - Images for artworks
- `category-order.json` - Order of works in each category

## Editing

When you push changes to this repository, the main website will automatically rebuild with your updates.
